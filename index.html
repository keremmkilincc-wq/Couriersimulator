⚡ Neler var?

GDD'nin oynanabilir karşılığı — hepsi tarayıcıda çalışıyor.

🏃

Sprint + Slide + Vault

Deparla ivme biriktir, barikat altından kay, kaputlardan vault ile uçarak geç. Slide-hop ile momentumu koru.

🧱

Wall-Run + Wall-Jump

Duvara hızlı sürt → duvarda koş. Çıkışta Space → karşı duvara sekmeye devam. Akışı bozma.

🌊

Flow State

5-7 sn temiz zincir → müzik yükselir, FOV açılır, %10 hız bonusu. Çarpınca sıfırlanır.

🚡

Zipline + Fan + Pano

Kırmızı kürelerde E → uç. Camgöbeği fanlar yükseltir, sarı panolar sektirir, mavi konteyner kurtarır.

📦

6 Paket Tipi

Kırılabilir, sıcak, ağır… Paketi seçmek = rotayı seçmek. Hasar ve ısı gerçek zamanlı işler.

🏅

Bronz / Gümüş / Altın

Süre + paket sağlamlığı dereceni belirler. Altın = x2.2 ücret + itibar. Skorlar tarayıcıda saklanır.
